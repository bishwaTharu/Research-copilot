## 📖 Architecture & Key Decisions (ADRs)

The system enforces deterministic processing over unbounded agents and guarantees non-hallucinatory citations:

1. **[ADR-1: Deterministic Ingestion](file:///c:/Users/bishw/research-copilot/docs/adrs/0001-deterministic-ingestion.md)**: Parsing is a checkpointed, resumable pipeline, not an agent. Agents are used strictly at query time.
2. **[ADR-2: Own the Schema](file:///c:/Users/bishw/research-copilot/docs/adrs/0002-own-the-schema.md)**: Every document parser maps into the canonical `PaperDoc` schema (blocks, bounding boxes, figures, tables, bibliography).
3. **[ADR-3: Citations Are Never Generated by the Model](file:///c:/Users/bishw/research-copilot/docs/adrs/0003-citations-never-generated-by-model.md)**: The model outputs retrieved evidence IDs only. Titles, DOIs, and page spans are resolved server-side from the database.
4. **[ADR-4: Local Embeddings](file:///c:/Users/bishw/research-copilot/docs/adrs/0004-local-embeddings.md)**: Pinned local embedding models (`all-MiniLM-L6-v2`) maintain vector index stability regardless of external provider fluctuations.
5. **[ADR-5: Adapter Around the Gateway](file:///c:/Users/bishw/research-copilot/docs/adrs/0005-adapter-around-the-gateway.md)**: All model access routes through `LLMAdapter` with exponential backoff on 429/5xx, structured output validation, provider header tracing, and caching.

## 🚀 Quickstart

### 1. Local Environment Setup

Ensure Python 3.11+ is installed. Dependencies can be managed with `uv`:

```bash
# Create virtual environment
uv venv
.venv\Scripts\activate

# Install dependencies
uv pip install fastapi uvicorn pydantic pydantic-settings aiohttp aiosqlite pymupdf rank-bm25 pillow python-multipart pytest pytest-asyncio
```

### 2. Configure Environment

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Key environment options:
- `GATEWAY_BASE_URL`: OpenAI-compatible endpoint (FreeLLMAPI on `http://localhost:3001/v1` or OpenAI/Ollama).
- `MODEL_MODE`: `auto` (smart free-tier routing) or `pinned` (explicit models for auditability).
- `PRIVACY_DEFAULT`: `allow_remote` or `local_only` (locks data to local compute).

### 3. Run the Backend & Web UI

Start the FastAPI application with auto-reload:

```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

- **Interactive Web UI**: Open [http://localhost:8000/](http://localhost:8000/)
- **Interactive OpenAPI Docs**: Open [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs)

### 4. Run with Docker Compose

To run the complete production-like stack (API, FreeLLMAPI, GROBID, PostgreSQL with pgvector, and Web):

```bash
docker compose up -d
```

## 🧪 Testing & Validation

### Run Unit and Integration Tests

The test suite validates schema integrity, section-preserving chunking, rate-limit backoff, and verifier fault-injection (fake IDs, altered quotes, negative bounding boxes):

```bash
pytest -v
```

### Run Evaluation Harness Benchmark (FR-EVAL-02)

Measures retrieval Recall@K, citation faithfulness, reference resolution accuracy, latency, and cost against the gold set:

```bash
python eval/runner.py
```

Generated reports are versioned under `eval/reports/`.
