**Research Copilot** is an open-source **AI research paper backend** and **scientific RAG (Retrieval-Augmented Generation) API** built with **Python**, **FastAPI**, **GROBID**, **MinerU**, and **PyMuPDF**. Unlike generic PDF pipelines that hallucinate references, Research Copilot enforces deterministic ingestion and strict claim verification—returning structured JSON and Server-Sent Events (SSE) grounded in exact PDF page coordinates, extracted LaTeX formulas, figure crops, and verified external citations via **Semantic Scholar**, **OpenAlex**, **arXiv**, **CrossRef**, and **Unpaywall**.

## ✨ Key Backend Capabilities

| Capability | Description |
| :--- | :--- |
| **Deterministic Multimodal Ingestion** | Checkpointed PDF pipeline combining **GROBID** (metadata, bibliography, citation mentions) with **MinerU** and **PyMuPDF** (layout-aware full-text blocks, reading-order preservation, page renders, figures, tables, and displayed LaTeX formulas) with SHA-256 deduplication and Stage 7 parse-quality reports. |
| **Audited Grounded Q&amp;A API** | Hybrid retrieval (local dense embeddings + BM25) feeding a structured Q&amp;A orchestrator and independent verifier that audits every claim with deterministic ID, quote, and bounding-box checks plus repair retries. |
| **4-Step Agentic Citation Verifier** | Extracts in-text citations (`[12]`, `(Author, Year)`), retrieves open-access full text of the cited paper (with honest abstract fallback for paywalled works), runs semantic search with an agentic self-correction loop, and streams live status steps over SSE (`/api/v1/papers/{paper_id}/verify-citation/stream`). |
| **Formula, Reference &amp; Notes APIs** | Dedicated REST endpoints for extracted equations (`/formulas`), cited-work full-text retrieval &amp; support checks (`/references/{id}/reader`, `/fetch`), dynamic paper-specific exploration questions (`/suggested-questions`), and anchored Markdown-exportable notes (`/notes`). |
| **Local-Only Privacy Mode** | Per-paper privacy enforcement (`/papers/{paper_id}/privacy`) that blocks all outbound LLM gateway and external academic API calls and falls back to on-device extractive hybrid retrieval with zero data transmission. |

## 📖 Architecture &amp; Key Decisions (ADRs)

The backend enforces deterministic processing over unbounded agents and guarantees non-hallucinatory citations:

1. **[ADR-1: Deterministic Ingestion](docs/adrs/0001-deterministic-ingestion.md)**: Parsing is a checkpointed, resumable pipeline, not an agent. Agents are used strictly at query time.
2. **[ADR-2: Own the Schema](docs/adrs/0002-own-the-schema.md)**: Every document parser maps into the canonical `PaperDoc` Pydantic schema (blocks, bounding boxes, figures, tables, formulas, and bibliography).
3. **[ADR-3: Citations Are Never Generated by the Model](docs/adrs/0003-citations-never-generated-by-model.md)**: The model outputs retrieved evidence IDs only. Titles, DOIs, and page spans are resolved server-side from the database.
4. **[ADR-4: Local Embeddings](docs/adrs/0004-local-embeddings.md)**: Deterministic local embeddings maintain vector index stability regardless of external provider fluctuations.
5. **[ADR-5: Adapter Around the Gateway](docs/adrs/0005-adapter-around-the-gateway.md)**: All model access routes through `LLMAdapter` with exponential backoff on 429/5xx, structured output validation, provider header tracing, and caching.

## 🚀 Quickstart

### 1. Local Environment Setup

Ensure Python 3.11+ is installed. Dependencies can be managed with `uv`:

```bash
# Create virtual environment
uv venv
.venv\Scripts\activate

# Install dependencies
uv pip install fastapi uvicorn pydantic pydantic-settings aiohttp aiosqlite pymupdf rank-bm25 pillow python-multipart pytest pytest-asyncio
```

### 2. Configure Environment

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Key environment options:
- `GATEWAY_BASE_URL`: OpenAI-compatible endpoint (FreeLLMAPI, OpenAI, or local Ollama).
- `MODEL_MODE`: `auto` (smart routing) or `pinned` (explicit models for auditability).
- `PRIVACY_DEFAULT`: `allow_remote` or `local_only` (locks paper data to local compute).

### 3. Run the FastAPI Backend

Start the FastAPI server with auto-reload:

```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

- **Health Check**: [http://localhost:8000/api/v1/health](http://localhost:8000/api/v1/health)
- **Interactive OpenAPI / Swagger Docs**: [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs)
- **ReDoc API Reference**: [http://localhost:8000/api/v1/redoc](http://localhost:8000/api/v1/redoc)

### 4. Run with Docker Compose

To run the backend stack (FastAPI API, LLM gateway, GROBID, and PostgreSQL with pgvector):

```bash
docker compose up -d
```

## ❓ Frequently Asked Questions (FAQ)

**How does Research Copilot prevent hallucinated citations?**  
The LLM is never allowed to invent titles, authors, or DOIs. It outputs only retrieved evidence IDs (`block_id`, `formula_id`, `figure_id`, `reference_id`), which a deterministic verifier audits against the parsed `PaperDoc` and bounding boxes before returning the response.

**Can Research Copilot verify citations to paywalled papers?**  
Yes. When an open-access PDF cannot be found via Unpaywall, Semantic Scholar, OpenAlex, or arXiv, the citation verification agent automatically falls back to the public abstract and sets `is_paywalled: true` with `source_basis: "abstract_only"`.

**Does it work with confidential or unpublished manuscripts?**  
Yes. Setting a paper's privacy mode to `local_only` via `POST /api/v1/papers/{paper_id}/privacy` blocks all remote LLM gateway and external academic API requests, switching to local on-device hybrid retrieval so zero document data leaves your machine.
